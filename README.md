# Beyou

A modern web application built with React, Vite, and Tailwind CSS v4.

## Getting Started

### Prerequisites

- Node.js (v22 or later recommended)
- npm or pnpm

### Installation

Clone the repository and install the dependencies:

```bash
npm install
# or
pnpm install
```

### Development

Run the development server locally:

```bash
npm run dev
# or
pnpm dev
```

The server will be available at `http://localhost:5173`.

### Build

To create a production build, run:

```bash
npm run build
# or
pnpm build
```

## Technologies Used

- **React 19**
- **Vite 8**
- **Tailwind CSS v4**
- **Framer Motion & GSAP** for animations
- **TypeScript**
